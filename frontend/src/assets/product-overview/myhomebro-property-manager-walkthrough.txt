From resident request to permanent property record



A property-management tour of resident intake, manager review, vendor coordination, completion evidence, and lasting maintenance history.



Welcome to MyHomeBro property operations. Here is how a resident maintenance need moves from first report to a complete, permanent property record.

The Property Manager Portal opens with a portfolio command center. Open requests, active work orders, properties, units, tenants, and preferred vendors are visible together, so the next action is clear.

Residents can report the affected property and unit, describe the problem, set urgency, grant access, and attach helpful evidence. Their secure status page shows what happened without exposing the manager workspace.

The manager reviews the facts and supporting files, requests more information when needed, records notes, and approves valid work. Closed requests stay available as read-only history instead of disappearing.

An approved request becomes a traceable work order. The manager can route it to a preferred vendor, a participating contractor, or internal staff while preserving the resident and source request context.

Scheduling uses clear date and time controls. During closeout, the manager can review completion notes, photos, receipts, or documents before marking the work complete and closing the maintenance request.

The property record connects each building with its units, tenants, vendors, systems, and completed maintenance. That history gives future decisions better context and keeps recurring issues easier to recognize.

Updates keep important changes visible, while finished requests and work orders move out of the active queue. Property teams can confirm what is pending, who is responsible, and what has already been completed.

MyHomeBro gives residents a clear reporting path and gives property teams an accountable workflow, from maintenance request to permanent property intelligence.
